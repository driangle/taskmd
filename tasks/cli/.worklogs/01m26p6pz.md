Started work. Root cause already diagnosed in conversation: `rootReachableSet`
in sdk/go/next/next.go builds the reachable set from the root's `depends_on`
upstream closure plus the root's own subtask subtree only — it never expands
subtask subtrees of upstream tasks, so subtasks of a decomposed upstream
dependency (and their own dependencies) are invisible to `next --root`.

**Approach:** rewrite `rootReachableSet` as a fixpoint worklist over both edge
types: for each reachable task, add its `depends_on` targets and its children
(childrenMap), until no new IDs appear. Add regression test with shape
R -> depends_on P; P has child S1; S1 depends_on D (actionable).
